# SmartPaws 🐾
**The ultimate AI-powered pet health and nutrition ecosystem.** 🚀

SmartPaws is a revolutionary, real-time pet care platform that optimizes your pet's feeding routine using machine learning. By combining high-precision weight sensors with a neural-ML engine, SmartPaws tracks nutrition, prevents food waste, and detects health anomalies before they become problems! ⚡️

## 🌟 Top Features
*   **🤖 AI Nutritionist**: A smart "Neural-ML" engine that learns your pet's eating habits to predict feeding times and portions.
*   **⚖️ Waste Optimization**: High-precision weight sensors ensure not a single gram of food is wasted.
*   **🏥 Health Anomaly Detection**: Instant alerts if your pet's appetite or weight trends show signs of illness.
*   **📱 Smart Dashboard**: A sleek, Glassmorphism web interface to manage your pet's health from anywhere.
*   **🔔 Telegram Sync**: Real-time SMS and Telegram alerts for low food levels or health warnings.
*   **☁️ Secure Cloud**: All historical feeding and health data is safely stored in Supabase for long-term analysis.

## ✨ Why SmartPaws?
Most pet feeders are "dumb" timers. SmartPaws is an intelligent caregiver. It doesn't just drop food; it understands your pet's biological needs, keeping your best friend healthy while saving you money on food waste.

*   **Smart Monitoring**: Track meal frequency, weight trends, and calorie intake in one premium interface.
*   **Predictive AI**: Our custom Gradient Boosting model predicts when your pet will be hungry based on 7+ biological markers.
*   **Remote Control**: Trigger a manual feed or adjust schedules instantly from the web app.

## 🛠️ Built With
*   **Frontend**: Next.js 15 + React 19 + Tailwind CSS (Glassmorphism UI)
*   **Backend**: Supabase (PostgreSQL & Realtime Auth)
*   **AI/ML**: OpenAI GPT-4o-mini (Nutrition Analysis) & Scikit-Learn
*   **Deployment**: Vercel Edge Network

## 🚀 Getting Started
### 1. Setup the Environment
Clone the repo and install the dependencies:
```bash
npm install
```

### 2. Configure Keys
Copy `.env.example` to `.env` and add your API keys for OpenAI and Supabase.

### 3. Launch the Dashboard
Run the development server:
```bash
npm run dev
```

## 📂 Project Structure
*   **/src/app**: The core App Router logic and sleek UI pages.
*   **/src/components**: Reusable high-end UI components (Modals, Charts, Sidebars).
*   **/src/lib**: Neural engines, Telegram alert logic, and Supabase client.
*   **/src/styles**: Premium global CSS and Tailwind configurations.
*   **/public**: High-quality 4K assets and app icons.
